# Content/Game

Questa cartella contiene tutti gli asset di gioco per Unreal Engine.

## Struttura

- **Blueprints/**: Blueprint actors, components, funzioni (`BP_*`)
- **UI/**: Widget Blueprint per interfaccia utente (`WBP_*`)
- **Maps/**: Livelli di gioco (es. `Map_Main`)
- **Data/**: Data Assets per tuning e configurazione (`DA_*`)
- **Audio/**: File audio (suoni, musica)
- **VFX/**: Effetti particellari e visivi
- **Meshes/**: Modelli 3D (palla, porta, campo, portiere)
- **Materials/**: Materiali e texture

## Naming Convention

Segui sempre le convenzioni di naming UE:
- `BP_` per Blueprint Actor/Component
- `WBP_` per Widget Blueprint
- `DA_` per Data Asset
- `M_` / `MI_` per Material/Material Instance
- `T_` per Texture
- `SM_` per Static Mesh
- `SK_` per Skeletal Mesh

## Note

Questa struttura sarà popolata durante lo sviluppo del progetto.
